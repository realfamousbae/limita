Лимиты Claude Code и Codex — одним взглядом на верх экрана Mac.

Limita — маленькое приложение для строки меню. Оно показывает, сколько осталось от 5-часового и недельного лимита, без терминала. Есть и версия для Windows, в трее.

Скачать для macOS Скачать для Windows

Версия 0.17.0 для macOS 14 и новее и Windows 10 или 11. Бесплатно, открытый код.

Не мешает, пока не понадобится

Ни окна, которое надо держать открытым, ни значка в Dock. Limita проверяет Claude каждые 3 минуты, Codex — каждые 5 и показывает цифры там, куда вы и так смотрите.

  • 5h 15% used

    Пилюля у верхнего края

    Задержите курсор у верхнего края любого экрана — выедет пилюля с 5-часовым лимитом каждого сервиса. Нажмите на неё, чтобы открыть дашборд. Чёлка и по 80 точек с каждой её стороны остаются другим приложениям.

  • ⌃control ⌥option L

    Одно сочетание из любого приложения

    Нажмите ⌃⌥L — дашборд откроется у верхнего края экрана, даже поверх полноэкранного терминала. Нажмите ещё раз, чтобы закрыть. В Windows это Ctrl+Alt+L.

  • ~/projects/app $ claude
    Claude 5h 52% · 7d 49% used │ Codex 5h 80% · 7d 64% left

    В строке состояния iTerm2

    Дополнительный плагин показывает лимиты в строке состояния вкладок, где запущен Claude Code или Codex, а в остальных её прячет. Нажмите на лимиты — откроется дашборд.

  • PEAK HOURS
    USAGE LIMITS RUN OUT FASTER
    • Claudeпо будням, 5–11 по тихоокеанскому времени
    • Codexпо будням, 12:00–18:00 UTC

    Знает часы пик

    В часы пик лимиты сервиса тратятся быстрее. Тогда в дашборде горит спидометр, а если в пике только один из двух сервисов, он назван.

  • Куда ушли токены

    Activity показывает токены по дням для каждого сервиса: за неделю, календарём за месяц или до полугода. Над графиком — всего токенов, любимая модель, сообщения и самый загруженный час.

  • LIMITA 0.17.0 IS OUTCLICK TO UPDATE

    Обновление в один клик

    Когда выходит новая версия, в дашборде появляется зелёная кнопка. Нажмите её — Limita скачает обновление, проверит подпись, установит его и перезапустится.

  • BANKED RESET · USE BY OCT 31
    DATA: CLAUDE-RESETS.COM
    RESET FOR EVERYONE · 5 HOURS AGO
    DATA: CODEX-RESET.COM
    Codex limits were reset for everyoneData: codex-reset.com

    Знает, когда лимиты сбросили

    Когда Anthropic или OpenAI сбрасывают лимиты всем, приложение для Mac пишет об этом в колонке сервиса и присылает уведомление. Ещё оно замечает, когда ваш недельный лимит начался заново раньше срока и когда Codex даёт сброс, который можно применить. Данные о сбросах для всех — с claude-resets.com и codex-reset.com.

Читает цифры, и больше ничего

Limita спрашивает лимиты у каждого сервиса так же, как его собственные инструменты. Ваши логины остаются на месте.

Claude Code

Limita берёт логин Claude Code из Связки ключей (macOS спросит один раз) и отправляет его только на api.anthropic.com — тот же запрос, что делает /usage в Claude Code. Логин она не хранит и не продлевает. Если запрос не удался, цифры берутся из строки состояния Claude Code.

Codex

Limita спрашивает сам Codex CLI через codex app-server, поэтому логин не покидает CLI. Если это не удалось, она читает последние лимиты из файлов сессий в ~/.codex.

  • Без аккаунтов, cookies и аналитики.
  • Промпты, транскрипты, пути проектов и ID сессий не читаются.
  • Кроме них Limita спрашивает GitHub об обновлениях, а приложение для Mac — claude-resets.com и codex-reset.com о сбросах подключённых сервисов. Ничего о вас и вашем использовании в этих запросах нет.

Установка

macOS 14 и новее

  1. Скачайте DMG, откройте его и перетащите Limita в Программы.
  2. Сборка пока не нотаризована. Для первого запуска нажмите на Limita в Программах правой кнопкой и выберите Открыть, или используйте Системные настройки → Конфиденциальность и безопасность → Всё равно открыть.
  3. При первом обновлении Claude macOS спросит, можно ли Limita читать Claude Code-credentials. Выберите Разрешать всегда.

Windows 10 или 11

  1. Скачайте установщик.
  2. Запустите его. Он ставит приложение для вашего пользователя, без прав администратора. Установщик пока не подписан: в предупреждении SmartScreen выберите Подробнее → Выполнить в любом случае.
  3. Limita ждёт в трее. Задержите курсор посередине верхнего края экрана, чтобы выехала пилюля.
